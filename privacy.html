Privacy Policy

Time-in-Status Badge for Jira Cloud
Last updated: 2026-08-24

This Privacy Policy explains what data Time-in-Status Badge ("the App") accesses, how it is used, and where it is stored.

What the App is

The App is an Atlassian Forge app that runs entirely inside Atlassian's Forge platform. It has no servers, databases, or infrastructure of its own outside of Forge — Atlassian hosts and secures the runtime and any stored data.

Data the App accesses

To calculate how long issues spend in each workflow status, the App reads the following from your Jira site using the read:jira-work permission scope:

  • Issue keys, summaries, and status change history (changelog)
  • Project and workflow status configuration
  • Your Jira account permissions, to confirm you're a project admin before allowing changes to project settings

This data is read on demand each time you open the issue panel, dashboard, or settings page. The App does not copy or persist your issue data — durations are calculated live and are not saved anywhere.

Data the App stores

The only data the App stores is project-level configuration that an admin explicitly sets, such as status thresholds and business-hours settings. This is stored using Forge's built-in storage:app API, which keeps it within Atlassian's Forge infrastructure for your site. No issue data, and no data about individual users, is stored.

CSV export

The dashboard's CSV export is generated and downloaded directly in your browser. No data is sent to the App's developer or to any third party as part of this feature.

Data sharing

The App does not sell, share, or transmit any data to third parties. It does not use analytics, tracking, or advertising services of any kind.

Data retention and deletion

Stored configuration (thresholds/business-hours settings) is kept until you change it or until the App is uninstalled from your site, at which point Atlassian removes the App's stored data in accordance with Forge's standard app-uninstall data handling.

Security

The App relies on Atlassian Forge's platform security model — it runs in Atlassian's infrastructure, under Atlassian's security and compliance controls, rather than on any infrastructure operated by the App's developer.

Contact

Questions about this policy or the App's data handling can be sent to support@releasybot.com.
